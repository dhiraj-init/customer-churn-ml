# ChurnIQ — Customer Churn Prediction System

ChurnIQ is an end-to-end machine learning application that predicts the likelihood of a telecom customer leaving a service.

The project covers the complete basic ML workflow — from raw data and preprocessing to model training, evaluation, serialization, and deployment through an interactive Streamlit application.

---

## 🚀 Features

- Customer churn prediction
- Churn probability estimation
- Low / Moderate / High risk classification
- Customer profile summary
- Rule-based churn risk indicators
- Retention suggestions
- Interactive Streamlit dashboard
- End-to-end Scikit-learn preprocessing pipeline

---

## 🎯 Problem Statement

Customer churn occurs when an existing customer stops using a company's services.

For businesses such as telecom providers, identifying customers who are likely to leave can help the company take preventive actions such as:

- Offering better plans
- Providing customer support
- Giving loyalty benefits
- Offering long-term contracts
- Improving customer engagement

The goal of this project is to use historical customer information to predict whether a customer is likely to churn.
